eg:

### [0.0.1] 2026-07-28

  * Initial tag created for the Core Cloud CodeArtifact Terraform module

### [1.0.1] 2026-08-04

  * Upstream repos must be created before associations are made

### [1.1.0] 2026-08-07

  * Adds cross-account policy support. Required for platform-shared CodeArtifact repos

### [1.1.1] 2026-08-07

  * Added package-scoped actions to policy permissions as well as the repo ARN
